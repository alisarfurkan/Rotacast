The simulation engine inside the app tests every option on the real weather of the past. For the Çumra field we run 179 different crop sequences, each with the real weather of 25 different start years from the 1991–2025 record: 4,475 simulations in total, each one day by day over several years. So we do not forecast; we test each option for a bad, a normal and a good year.
